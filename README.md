# ANVIL 

A full-stack habit and fitness tracking application designed to map consistency over time. 

 ## Live Demo: (https://anvil-app-chi.vercel.app/)

## TECH STACK
FRONTEND: HTML , CSS, Vanilla Javascript (deployed on VERCEL)
BACKEND: Python , Fastapi , Uvicorn (deployed on RENDER)
Architecture: fully decoupled restapi

## FEATURES
user authentication: secure signup and login flow
task management: real-time task syncing and updates
consistency matrix: visual heat-map tracking daily progress , similar to github's contribution graph
